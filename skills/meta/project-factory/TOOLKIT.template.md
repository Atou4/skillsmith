## Lessons

(Reusable lessons that hold beyond one project. Project-specific facts go in that project's STATE.md.)

- `npx skills add` without `--agent` links a skill into many agents' folders. Always name the agents.
- Installed skills appear in a session only after a restart.
- Some repos listed on skills.sh have no valid SKILL.md and the CLI refuses them. Do not count a skill as installed until you see its folder.
